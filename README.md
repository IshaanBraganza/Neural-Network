The project directory for 2 neural networks:

1. The Number Classification
2. The Shape Classification

The number classification model will work with the popular MNIST dataset to classify numbers 0-9.
The shape classification model will be trained on a 10x10 grid which can have 3 different shapes: squares, circles, or triangles. The shapes can also have differing size, and it will learn to classify them.

__The shape classification model will be done first, then the number classification model, where then I hope to develop a model which takes in an N number of input neurons, N number of hidden layers, Ni number of neurons per hidden layer where i is the specific hidden layer, and N number of output neurons. Hopefully this aims to make it easier for someone to make a neural network, and maybe also be used in my upcoming projects.
